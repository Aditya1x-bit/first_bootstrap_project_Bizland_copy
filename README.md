# BizLand Website

This is a modern, responsive website built using HTML, CSS, and Bootstrap, based on the BizLand template. It includes features like a newsletter subscription, a contact section, a footer with useful links, social media icons, and a scroll-to-top button. The website also includes an image lightbox feature for displaying images in a modal format.

## Features

- **Responsive Layout**: Designed to be mobile-first with Bootstrap's grid system.
- **Newsletter Subscription**: A simple form that allows users to subscribe to the newsletter.
- **Footer**: Includes company details, useful links, services, and social media icons.
- **Scroll to Top Button**: A button fixed at the bottom right that lets users scroll back to the top of the page.
- **GLightbox Integration**: Lightbox functionality for image galleries.
- **Custom JavaScript**: For features such as carousel clones and lightbox initialization.

## Technologies Used

- **HTML**: Used for the structure of the website.
- **CSS**: Custom styling to complement the default Bootstrap styles.
- **Bootstrap 5**: A responsive framework that helps to design the layout and components.
- **JavaScript**: For custom functionality like the newsletter form, carousels, and lightboxes.
- **GLightbox**: A library for creating beautiful, responsive lightboxes for images.

## Installation

### Prerequisites

- A modern web browser (e.g., Chrome, Firefox).
- A code editor (e.g., VSCode) if you wish to make modifications.
